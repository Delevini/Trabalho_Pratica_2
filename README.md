Este projeto, desenvolvido para a disciplina de **Prática 2**, consiste em um **Shiny Dashboard** interativo dedicado à análise comparativa de métodos de estimativa de concentração de **PM2.5** no estado do Espírito Santo, confrontando dados dos modelos **CAMS** e **Donkelaar** para os anos de 2022 e 2023. A aplicação integra análises temporais via boxplots, visualização espacial com mapas de distribuição e diferença por município, além de validação estatística robusta através de gráficos de dispersão, Bland-Altman e testes de concordância (ICC/Correlação), acessível diretamente pelo navegador através deste [link para o dashboard](https://e67s5p-leonardo-vinicius.shinyapps.io/Analise-PM25-ES/).
